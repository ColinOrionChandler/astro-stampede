Astro Stampede
==============

A local browser application for reviewing astronomical PNG cutout sequences.
Browse object queues, animate and compare images, score with the keyboard,
and export classifications with their audit history. Model scores stay hidden
until you choose **Reveal**.

Start with the synthetic demo. Source images remain read-only; the application
is designed for one local review process, not concurrent hosted sessions.
